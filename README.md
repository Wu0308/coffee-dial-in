## 一、 風味雷達圖的原理：我們如何科學預測一杯咖啡的風味？

在精品手沖世界裡，一杯咖啡好不好喝，並非玄學。從生豆受熱烘焙、研磨成顆粒，到熱水接觸咖啡粉溶出芳香物質，每一步都是可量化的化學反應。

BrewCraft 的「感官風味雷達圖」並非隨機擺設的裝飾圖形，而是**綜合了烘焙度、沖煮手法、研磨粗細、水溫微調、粉水比與各段注水結構**等多重變數後，即時推算出的感官風味光譜。

```
              酸質 (Acidity)
                  /\
                 /  \
  乾淨度        /    \        甜感
(Cleanliness) /      \    (Sweetness)
              \      /
               \    /
                \  /
                 \/
          醇厚度     餘韻
          (Body)  (Aftertaste)
```

### 1.1 五大感官維度代表什麼？

參考精品咖啡協會（SCA）杯測感官評鑑標準，系統選取最能定義手沖品質的五個核心向度：
* **酸質 (Acidity)**：指咖啡中的活潑有機酸（如檸檬酸的柑橘感、蘋果酸的脆爽感）。高分代表果酸明亮多汁、層次細緻；低分代表低酸溫和或以苦味為主。
* **甜感 (Sweetness)**：指咖啡中的可溶性醣類飽滿度。高分代表熟果甜、焦糖與蜂蜜感明顯，入口滑順圓潤。
* **醇厚度 (Body)**：指咖啡液在舌面上的重量感、濃稠感（Mouthfeel）與油脂包覆度。高分代表濃郁厚實，低分代表質地輕盈清爽。
* **餘韻 (Aftertaste)**：指吞嚥後芳香分子在喉頭咽壁留存的時間長度與回甘表現。高分代表尾韻悠長、甘甜持續。
* **乾淨度 (Cleanliness)**：指整杯咖啡的通透程度，杯中完全沒有木質味、過萃苦澀或細粉泥狀的混濁雜味。

---

### 1.2 烘焙度：決定風味的「基底色盤」

咖啡豆烘焙是一場「有機酸分解」與「焦糖化／梅納反應」的化學轉化：
* **淺焙（Light）**：烘焙時間短，咖啡豆保留了最多的綠原酸與檸檬酸，此時**酸質最高、杯中極致乾淨**；但因焦糖化反應較少且油脂未完全釋出，醇厚度最低。
* **中焙（Medium）**：焦糖化反應達到顛峰，酸質逐漸收斂，熟果與焦糖甜感最大化，酸、甜、甘、醇四大光譜達到**金杯級的最佳平衡**。
* **深焙（Dark）**：豆體內部纖維深度碳化，有機酸幾乎完全分解，油脂大量浮上表面，**醇厚度（Body）達到頂峰**，轉為黑巧克力、堅果與煙燻芳香，乾淨度則因微細粉與烘烤產物增加而下降。

系統會先以您選擇的烘焙度作為「基底分佈」，再依據後續的沖煮手法與操作進行微調。

---

### 1.3 沖煮手法：決定風味「層次與萃取率」

即使是同一支豆子，用不同手法沖煮，風味表現也會截然不同：
* **粕谷哲 4:6 法**：使用偏粗研磨，每段注入後等待水層完全排乾。這種「多次斷水 + 粗顆粒表面洗滌」能大幅降低尾段細粉過萃機率，讓**甜感顯著提升、口感格外乾淨**。
* **一刀流（Single Pour）**：以極細柔和水流連續不間斷注水。水流對粉床的攪動極低，粉床充當了天然濾層，萃取出的咖啡液**乾淨通透如茶，酸質明亮**，但醇厚度略低。
* **經典三段式**：由內向外穩定均勻螺旋繞圈，維持穩定水層高度，中段風味層次均勻釋放，能萃出**飽滿的醇厚度與回甘**。
* **James Hoffmann V60**：前期大水流衝擊加上旋轉晃動濾杯（Swirl），能打破粉床內的乾粉結塊並拉平粉床，萃取率極高且穩定，帶來**高甜感與豐富餘韻**。
* **松屋法（Matsuya）**：加蓋長時間深悶蒸只萃取前段最高濃度的甜美物質，尾段移開濾杯直接加熱水（Bypass），徹底避開中後段木質苦味，因此**乾淨度極高**。
* **Switch 聰明濾杯浸泡法**：閉閥全浸泡萃取，微細粉與油脂充分懸浮在水體中，能萃出**最強烈的厚實飽滿感（Body）**。

---

### 1.4 研磨顆粒：控制「水粉接觸面積與阻力」

咖啡粉研磨的粗細，本質上是在調控**固液接觸面積**與**水流滲透阻力**：
* **偏細研磨**：顆粒小、總表面積暴增，水流通過阻力大、接觸時間長。因此會萃出更多的油脂與固形物，**醇厚度與餘韻顯著提升**；但若水流控制不慎，也容易萃出後段雜苦味，使乾淨度下降。
* **偏粗研磨**：顆粒大、總表面積較小，水流能快速流過。萃取主要發生在顆粒表面，因此優先溶出溶解度極高的小分子有機酸，**酸質明亮、乾淨清澈**，但口感較輕薄。

系統提供 8 階研磨度連動，微調時雷達圖會即時反映比表面積變化帶來的感官影響。

---

### 1.5 水溫與粉水比：控制「分子熱能與濃度厚度」

* **水溫調校（熱力學效應）**：
  * **提高水溫（+1°C ~ +3°C）**：熱水分子的運動能量增加，滲透效率提升，最容易萃出揮發性花果香酸氣與細緻甜感；若深焙豆水溫過高則容易燙出焦苦。
  * **降低水溫（-1°C ~ -3°C）**：萃取過程溫和，水溫不足以溶解難溶的大分子苦澀單寧物質，因此能**大幅提升純淨度**，適合深焙豆或想避免苦澀時使用。
* **粉水比調校（濃度 TDS 效應）**：
  * **寬粉水比（如 1:16 ~ 1:18）**：水量充沛，整體溶解濃度稀釋，口感轉為輕盈柔和，**果酸更通透、層次乾淨**。
  * **窄粉水比（如 1:12 ~ 1:14）**：水量少而粉量足，萃出液的濃度（TDS）顯著拉高，微乳化油脂感強烈，帶來**黏稠濃厚的 Body 與長效回甘**。

---

### 1.6 注水結構與悶蒸時間：掌握「酸甜主軸」的動態奧秘

在時間軸中自訂參數時，系統還會進一步分析注水的微觀結構：
* **粕谷哲 4:6 前段比例**：若第一注水量較大（前大後小），前段大水量會快速帶出果酸；若第一注水量小、第二注水量大（前小後大），則能延長蔗糖焦糖化溶出時間，甜感更突出。
* **悶蒸時間長短**：短悶蒸（$\le 35$ 秒）排氣快、節奏輕快，保留清新果酸；長悶蒸（$\ge 50$ 秒）深度受熱均勻，能充分釋放深層焦糖甜感與醇度。
* **總萃取時間**：快流速能避開尾段單寧苦味；長接觸則能萃出更多油脂厚度。

## 二、 注水流速與曲線引擎：為什麼流速不能千篇一律？

### 2.1 傳統工具的盲點：為什麼不能把水量直接除以總秒數？

許多沖煮工具計算建議流速時，會直接使用：
$$\text{流速} = \frac{\text{階段水量}}{\text{階段總秒數}}$$

**在專業手沖吧台上，這個算法是完全脫離現實的。**
例如：一個階段「注入 50g 水，時長 40 秒」，如果真的一路注水注滿整整 40 秒，水流會細如一根針（約 $1.2\text{ g/s}$），不僅水柱在空氣中迅速散熱失溫，還會因為水層遲遲建立不起來而導致萃取不足。

真實的手沖流程是：**在合理的前半段時間內注完目標水量（出水期），後半段留給水層自然向下滲透濾乾（滴漏期）**。
因此，計算建議流速時，必須先推算出**真實的注水秒數**，而非單純除以總秒數。

---

### 2.2 為什麼不同手法需要完全不同的水流強度？

在手沖過程中，水流大小代表了**「水流動能（Agitation）」**。不同的手法與萃取階段，目的完全不同，絕不能千篇一律：

* 🌊 **大水流（強攪拌，約 4.5 ~ 5.5 g/s）**：
  * **目的**：利用較大的衝擊動能創造水層紊流（Turbulence），翻滾粉床、沖散乾粉結塊，並防止極細微粉過早沉積在濾紙底部造成堵塞。
  * **代表場景**：James Hoffmann 第一段大水流注入、4:6 法後段快速注水拉升水位。
* ⚖️ **標準水流（平衡均勻，約 3.0 ~ 3.8 g/s）**：
  * **目的**：維持穩定同心圓螺旋繞圈，建立均勻的水層高度與穩定的靜水壓，使風味平衡釋出。
  * **代表場景**：經典三段式注水、4:6 法前段風味調整。
* 🌿 **柔和小水流（低擾流，約 2.0 ~ 3.0 g/s）**：
  * **目的**：垂直低落差注水，水流呈平穩層流（Laminar flow），幾乎不衝擊擾動粉層，保護粉床的天然過濾孔隙，避免擊穿通道效應。
  * **代表場景**：一刀流全段不間斷細注水、Hoffmann 第二段溫和補水。
* 💧 **極細點滴（滲透排氣，約 1.0 ~ 1.6 g/s）**：
  * **目的**：手沖壺極輕微傾斜，一滴一滴如點滴般滴在中心，完全不衝擊粉床，純靠毛細現象由粉芯內部緩慢滲透潤濕排氣。
  * **代表場景**：松屋法長達 30 秒的中心點滴深悶蒸。
* 🫗 **旁路直注（Bypass，約 8.0 ~ 8.5 g/s）**：
  * **目的**：移開濾杯，直接向分享壺注入熱水稀釋，完全不經濾杯，注水速度極快。
  * **代表場景**：松屋法最後加入純熱水調節濃度。

---

### 2.3 系統如何推算合理流速與注水秒數？

BrewCraft 為每個步驟指派了專業的「水流型態（Flow Profile）」，計算引擎會依序執行：
1. **依水流型態的目標流速推算所需出水秒數**：
   例如設定大水流（基準 $4.8\text{ g/s}$），注入 $105\text{g}$ 水約需 $22$ 秒注完。
2. **預留合理的收水滴漏時間（Drain Buffer）**：
   例如段落總長 $35$ 秒，扣除 $22$ 秒注水，剩餘 $13$ 秒讓水層平靜過濾與沉降。
3. **安全物理極限保護**：
   自動校驗單段流速上限（大水流上限放寬至 $6.5\text{ g/s}$，Bypass 直注上限 $12\text{ g/s}$），確保推算出的秒數與流速在物理上真實可行。
4. **即時流速對齊**：
   卡片標註的「約 Xs 注完」、建議流速數值、注水曲線 Tracker 的幾何斜率，以及全螢幕 Zen Barista HUD 的即時指示，**100% 來自同一套引擎，精確同步**。

| **一刀流** | 主注水段 | **`柔和小水流`** | 188g | 65s | **約 62 秒** | **~3.0 g/s** | 3 秒 | 長達 62 秒極細穩定垂直水柱不中斷，均勻長斜坡注滿。 |

### 2.5 為什麼注水曲線是「階梯斜率」？

在 BrewCraft 的注水曲線追蹤器（Water Curve Tracker）中，曲線並非隨意畫出的弧線，而是由**「出水爬升斜坡」**與**「靜置水平走線」**交替構成：

```
水量 (g)
  ^               ┌────────── 階段 2 結束 (水層滴乾，移開濾杯)
  |            .─'  (水平走線：滴濾滲透 0.0 g/s)
  |         .─'  (陡峭斜坡：第二段注水進行中)
  |      ┌──'  (水平走線：第一段注完，水層沉降靜置)
  |   .─'  (斜坡：第一段注水)
  +──'─────────────────────────> 時間 (秒)
```
* **出水時（斜坡）**：線條陡峭向上攀升，斜率越陡代表水流越急（如大水流 ~5.0 g/s）；斜坡較緩則代表細柔水流或點滴。
* **滴漏時（水平平走）**：停止注水後，目標水量不再增加，線條維持水平延伸，代表咖啡液正在穿透粉床向下濾乾。

計時器啟動時，發光的綠色指示球（Playhead Puck）會即時在曲線上推進，讓您在注水時一目了然「現在該注多快、何時該停手等待落乾」。

### 2.6 智慧自適應警示：不再盲目跳「流速過快」警告

當使用者在時間軸中手動編輯秒數與水量時，系統會智慧對比所選水流型態的安全範圍：
* **大水流模式**：系統知道您打算進行紊流翻滾，因此將安全上限放寬至 $6.5\text{ g/s}$，沖 $5.0\text{ g/s}$ 時不會誤跳通道效應警告。
* **點滴模式**：系統知道您正在一滴滴浸潤中心，因此將下限放寬至 $0.6\text{ g/s}$，不會誤跳溫度散失過快警告。
* **真正異常時才提醒**：只有在流速真正過於極端（例如用細水流卻試圖在 5 秒內注完 100g，算出的流速已超出物理安全範圍）時，才會精準跳出專業調整建議。

## 四、 核心系統架構與專業吧台功能

### 4.1 Zen Barista 沉浸式全螢幕吧台模式 HUD
專為手沖操作時維持遠距視讀而設計的原生 `<dialog>` 全螢幕專注儀表板：
* **巨幅高對比度數值讀數**：支援 `124px` 超大字體即時秒數顯示，搭配 `text-7xl` 累計注水目標克數，手持手沖壺站立於吧台 1 公尺外亦能清晰視讀。
* **分段進度條（Segmented Progress Rail）**：將沖煮全程拆解為獨立注水區塊，即時回饋各區塊進度，完成後點亮翡翠綠。
* **內嵌即時微型注水曲線**：彈窗底部同步繪製 mini SVG 曲線與即時流速指示器。

### 4.2 Step Timeline Rail 時間軌與自訂微調器
* **里程碑軌道**：包含序號圓標、階段名稱、時間區間、注水量、累計目標及專業水流型態徽章（如 `[大水流 ~4.8 g/s]`、`[極細點滴 ~1.2 g/s]`）。
* **無刷新局部重算**：在編輯模式下鍵入數值時，保持輸入焦點不跳脫，累計水量、秒數、粉水比與警示動態局部更新。
* **水流風格切換膠囊**：提供 `[大水流]` `[標準]` `[小水流]` `[點滴]` 按鈕，點擊即刻連動建議時長與曲線斜率。

### 4.3 Web Audio API 柔和無依賴和弦音訊
* **倒數滴答聲**：每段結束前 3 秒輕柔短音（880Hz / 1760Hz）。
* **換段雙音和弦**：階段交接發出清脆 C5 + E5 合音（523Hz + 659Hz）。
* **完成上揚三和音**：沖煮完成發出溫暖的 C5 $\to$ G5 上揚和聲，提示移開濾杯。

### 4.4 Coffee Beans Vault 咖啡豆評分庫與參數封裝
* **多手法杯測記錄**：建立咖啡豆檔案（豆名、烘焙度、產區處理法），記錄不同手法下的感官星等評分與風味標籤。
* **參數完整封裝**：儲存時自動封裝當時的粉量、水溫、研磨度、粉水比、總水量與所有階段的自訂注水細節。
* **一鍵套用**：歷史清單中點擊「套用此參數」，主介面 100% 還原所有手法配置。
* **LocalStorage 本地持久化**：資料完全儲存於使用者瀏覽器本機，無需註冊登入，保護隱私。

## 六、 本地開發與快速啟動指南

BrewCraft 採用零建置（Zero-build）純前端現代工藝，無需安裝 Node.js、npm 或任何打包工具，單一靜態檔案即可立即運作。

### 方式一：Python 內建伺服器（推薦）
```bash
git clone https://github.com/wu0308/coffee-dial-in.git
cd coffee-dial-in
python -m http.server 3000
```
開啟瀏覽器訪問：`http://localhost:3000`

### 方式二：Node.js http-server
```bash
npx http-server -p 3000
```

### 方式三：直接開啟
雙擊專案目錄下的 `index.html`，即可直接在任何現代瀏覽器（Chrome, Edge, Safari, Firefox）中開啟執行。
