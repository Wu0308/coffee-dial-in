## 核心特色與三大升級架構

### 1. Zen Barista 沉浸式吧台模式 HUD
專為吧台沖煮時維持遠距視讀而設計的原生 `<dialog>` 全螢幕專注儀表板：
- **巨幅高對比度數值讀數**：支援 `124px` 超大字體即時秒數顯示，搭配 `text-7xl` 累計注水目標克數，即便手沖壺在手、站立於手沖吧台前 1 公尺處亦能清晰一目了然。
- **分段進度條（Segmented Progress Rail）**：將沖煮全程拆解為具體注水階段，即時回饋各階段當前秒數進度與累計落水目標。
- **全鍵盤快捷鍵無縫掌控**：
  - `Space`：開始 / 暫停沖煮計時。
  - `Esc`：安全退出全螢幕 HUD 模式。
  - `ArrowRight`：快轉至下一注水階段。
  - `ArrowLeft`：回溯至上一注水階段。

### 2. Sensory Flavor Radar 5 維感官風味雷達光譜
基於精品咖啡感官杯測標準（SCA Sensory Evaluation Standard）建立的即時動態 SVG 蜘蛛網雷達多邊形引擎：
- **五大感官維度**：
  - **酸質 (Acidity)**：評估有機果酸的活潑度與明亮度。
  - **甜感 (Sweetness)**：評估焦糖化與美拉德反應帶來的成熟甜感與滑順度。
  - **醇厚度 (Body)**：評估咖啡萃取總固體溶解量（TDS）與油脂包覆感。
  - **餘韻 (Aftertaste)**：評估吞嚥後香氣留存時間與回甘表現。
  - **乾淨度 (Cleanliness)**：評估杯中無雜味、過萃苦澀或細粉混濁感的透亮程度。
- **動態多參數全向聯動**：
  - 烘焙度基礎權重（淺焙、中淺焙、中焙、中深焙、深焙）。
  - 手沖手法流速微調（四六法、三段式、Hoffmann V60、一刀流、松屋法、Switch 浸泡法）。
  - 風味偏好微調（強調酸質、突出甜感、追求厚實、平衡順口）。
  - 水溫偏移量微調（高溫促進芳香族化合物與油脂溶解，低溫保留果酸與輕盈甜感）。
  - 粉水比偏移量微調（低比率濃郁醇厚，高比率乾淨清澈）。
  - **研磨度 8 階動態微調**：從極細研磨（高萃取、濃郁醇厚、餘韻悠長）至粗研磨（清澈乾淨、明亮果酸），調整選單即刻連動雷達多邊形形狀、五維長條圖數值與萃取診斷提示。
- **智慧吧台萃取診斷**：根據五維得分與自訂參數，即時生成風味特徵報告與調校建議（例：「目前自訂極細研磨，顆粒極細萃取率高，顯著提升醇厚度與餘韻」）。

### 3. Step Timeline Rail 注水階段時間軌與自訂調校
以單一時間軌取代繁雜資料表格，呈現簡潔流暢的注水節奏：
- **垂直里程碑軌道**：各階段具備序號圓標、階段名稱、時間區間、注水量、累計目標及建議注水流速（g/s）。
- **即時沖煮行進狀態**：
  - 未開始：淡灰邊框與序號標籤。
  - 進行中：琥珀色光環脈衝外框、高亮聚焦卡片。
  - 已完成：深焙實心圓標搭配翡翠綠勾勾，卡片低調淡化。
- **完備的自訂各段參數編輯模式**：
  - 點擊「自訂各段秒數與水量」，時間軌節點即刻轉化為精確輸入欄位。
  - **局部更新無跳游標**：輸入任一段注水量或秒數時，累計目標、粉水比、時間區間與預估總時長即時動態重算，打字過程焦點不跳脫。
  - **客製操作簡記**：每一階段皆可自由撰寫個人的注水要領（例：「中心點極細水流點滴注入」），留存於計時導引與評分記錄中。
  - 點擊「完成自訂編輯」即刻無縫切換回優雅時間軌視圖；點擊「恢復推薦」隨時還原金杯標準配置。

### 4. 專業級互動式沖煮計時器與動態動畫導引
- **Web Audio API 柔和非侵入式雙音和弦**：
  - 倒數提示：每段結束前 3 秒輕柔倒數滴答聲（880Hz / 1760Hz）。
  - 換段提示：階段交接發出雙音和弦合音（523Hz + 659Hz，C5/E5）。
  - 完成提示：沖煮結束發出溫暖上揚雙音和聲（523Hz 至 784Hz，C5 至 G5）。
- **動態手沖幾何動畫導引（Step Cue Animations）**：
  - 溫潤深層悶蒸排氣（粉層膨脹排氣動態）。
  - 穩定螺旋繞圈注水（同心圓漣漪擴散動態）。
  - 垂直中心點滴注入（極細垂直水柱漣漪）。
  - 旋轉搖晃均勻浸潤（Hoffmann Swirl 濾杯旋轉）。
  - 閥門閉合全浸泡（Switch 聰明濾杯全浸潤）。
  - 開閥釋放重力滴濾（Switch 濾液流下釋放）。
  - 自然滴濾平整收尾（水層緩緩排乾）。
- **真實時間戳校準（VisibilityChange）**：在手機螢幕關閉、分頁切換後返回時，依真實時間戳毫秒不差校準當前秒數。
- **超時滴漏等待機制（Overtime Drip-Through）**：達到預估時間時計時器平滑轉為超時滴漏計時（顯示 `+XX 秒`），等待濾杯完全滴乾後再移開濾杯。
- **螢幕防休眠（Screen Wake Lock API）**：沖煮期間自動保持手機螢幕常亮。

### 5. 咖啡豆評分庫與參數封裝 (Coffee Beans Vault)
- **多手法杯測記錄**：建立咖啡豆檔案（豆名、烘焙度、產區處理法），針對同一支咖啡豆記錄不同手沖手法與風味表現。
- **完整參數封裝與回溯**：評分時自動封裝當時的粉量、水溫、研磨度、粉水比、總水量與各階段注水細節。
- **一鍵「套用此參數」**：歷史清單中點擊套用按鈕，主畫面立即 100% 還原所有手法設定、烘焙度、風味偏好與各段秒數水量。
- **LocalStorage 本地持久化**：資料完全儲存於使用者瀏覽器本機，無需註冊登入，保護隱私。

## 6 大主流手沖手法科學模型

| 沖煮手法 | 特色與萃取原理 | 建議研磨度 | 水溫配置 | 預估總時長 |
| :--- | :--- | :--- | :--- | :--- |
| **粕谷哲 4:6 法** | 前 40% 水量決定酸甜平衡，後 60% 水量均分調節濃淡醇厚 | 偏粗研磨 | 92°C | 約 3:15 |
| **經典三段式** | 悶蒸透徹後分兩段注水，萃取均衡，層次分明 | 中細研磨 | 90°C | 約 2:30 |
| **Hoffmann V60** | 60% 大水流擾動 + Swirl 消除通道效應，萃取率極高且穩定 | 中細偏細 | 94°C | 約 3:30 |
| **職人一刀流** | 悶蒸後極細垂直水流連續不斷水注入，水粉接觸均勻順滑 | 中細研磨 | 91°C | 約 2:10 |
| **松屋法 (Matsuya)** | 極粗研磨長達 3 分鐘蒸氣悶蒸，前段濃縮萃取，後段以熱水稀釋 | 粗研磨 | 88°C | 約 5:00 |
| **聰明濾杯浸泡法** | 前段關閥全浸泡萃取甜感油脂，後段開閥重力滴濾清澈口感 | 中度研磨 | 93°C | 約 3:15 |

## 風味偏好與萃取科學對照表

| 風味目標 | 水溫調校 | 粉水比調校 | 悶蒸時長與節奏 | 萃取科學機制 |
| :--- | :--- | :--- | :--- | :--- |
| **強調酸質 (Acidity)** | +1°C (例 93°C) | 標準基準 | 縮短至 35 秒，快節奏落水 | 快速提取揮發性花果有機酸，避開後段大分子單寧苦澀 |
| **突出甜感 (Sweetness)** | -1°C (例 91°C) | 1:15.2 微幅加寬 | 延長至 52 秒，多段均勻潤濕 | 給予可溶性寡糖與焦糖化物質充分溶解時間，層次豐潤 |
| **追求厚實 (Body)** | -2°C (例 90°C) | 1:14.0 收窄比例 | 延長浸潤接觸時間 (+20s) | 提高咖啡萃取液 TDS 濃度，萃取乳化油脂與飽滿包覆感 |
| **平衡順口 (Balance)** | 標準水溫 (92°C) | 1:15.0 金杯比例 | 45 秒標準悶蒸 | 酸、甜、苦、甘四大光譜均衡對稱，展現產區本真特色 |

## 研磨粗細 8 階對照表與感官動力學

BrewCraft 支援 8 階精密研磨刻度，研磨粗細直接改變咖啡粉顆粒接觸表面積與水流阻力：

| 研磨等級 | 顆粒參考對照 | 水流通過阻力 | 感官風味光譜影響 | 適用場景 |
| :--- | :--- | :--- | :--- | :--- |
| **極細研磨** | 細砂糖 / 意式偏粗 | 極高 | 醇厚度 +0.6、餘韻 +0.3、乾淨度 -0.6、酸質 -0.4 | 濃郁萃取、極深烘焙降酸 |
| **細研磨** | 精細海鹽 | 高 | 醇厚度 +0.4、甜感 +0.3、乾淨度 -0.4、酸質 -0.2 | AeroPress、濃郁短注手沖 |
| **中細偏細** | 食用精鹽 | 中偏高 | 醇厚度 +0.2、甜感 +0.2、乾淨度 -0.2、酸質 -0.1 | Hoffmann V60、淺焙慢萃 |
| **中細研磨** | 白砂糖 (標準) | 中等基準 | 金杯平衡基準 (酸質 3.5, 甜感 4.4, 醇厚 3.8) | 經典三段式、一刀流標準 |
| **中度研磨** | 粗海鹽 | 中偏低 | 乾淨度 +0.2、酸質 +0.1、醇厚度 -0.1 | 聰明濾杯 Switch 浸泡 |
| **中粗研磨** | 粗岩鹽 | 低 | 乾淨度 +0.3、酸質 +0.3、醇厚度 -0.3 | 深焙避苦、快速導流濾杯 |
| **偏粗研磨** | 黑胡椒粗粒 | 極低 | 乾淨度 +0.4、酸質 +0.4、醇厚度 -0.4 | 粕谷哲 4:6 法標準配置 |
| **粗研磨** | 粗石顆粒 | 阻力微弱 | 乾淨度 +0.6、酸質 +0.5、醇厚度 -0.6 | 松屋法、法壓壺、冷萃濾泡 |

## 本地開發與快速啟動指南

BrewCraft 採用零建置（Zero-build）現代前端工藝，無需安裝 Node.js、npm 或打包工具，單一靜態檔案即可立即運作。

### 方式一：Python 內建伺服器（推薦）
```bash
git clone https://github.com/wu0308/coffee-dial-in.git
cd coffee-dial-in
python -m http.server 3000
```
開啟瀏覽器訪問：`http://localhost:3000`

### 方式二：Node.js http-server
```bash
npx http-server -p 3000
```

### 方式三：直接開啟
雙擊專案目錄下的 `index.html`，即可直接在任何現代瀏覽器（Chrome, Edge, Safari, Firefox）中開啟執行。

## 技術規格與設計標準

- **架構**：Vanilla HTML5 + 原生現代 JavaScript (ES6+)
- **樣式系統**：Tailwind CSS CDN + 暖麻極簡精品工藝設計規範
- **色盤規範**：
  - 底色：`#F5F2EB` (Warm Linen 暖麻紙質)
  - 卡片：`#FAF8F5` / `#FFFFFF` (純淨陶瓷白)
  - 邊框：`#E6DFD7` (柔和米褐)
  - 標題與數值：`#2C2521` (深焙咖啡黑)
  - 強調色：`#654D3F` (意式濃縮褐) / `#D97706` (琥珀金)
  - 狀態指示：`#10B981` (翡翠綠萃取完成)
- **視覺圖示**：100% 自行繪製之輕量 SVG 向量圖示，嚴格零 Emoji、零雜亂字符。
- **音訊架構**：原生 Web Audio API 合成振盪器（Sine Oscillator + Exponential Decay），零外部音訊檔案依賴。
- **離線支援**：PWA Service Worker + Manifest，支援完全離線快取運行。
- **介面品質檢查**：通過 `impeccable detect` 驗證，零 Anti-patterns 違規。
