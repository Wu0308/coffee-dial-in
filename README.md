## 一、核心亮點

1. **三維物理自適應與濾杯幾何模型**：以烘焙度（5 階）、粉量（`8g–50g`）、6 大經典沖煮手法與 3 種手沖濾杯幾何結構（錐形 V60／平底蛋糕／梯形扇形，另搭配浸泡法橫切面示意）動態連動，自動修正粉層厚度阻力、悶蒸時間與落水秒數，並顯示濾杯特性簡介。
2. **熱手沖 × 冰手沖熱力學模型**：冰手沖採用下壺 `35%` 冰塊 + 上壺 `65%` 熱水拆分，自動補償水溫 `+2°C`、調細研磨 1 階與 `1.15x` 落水修正；同時強制保護熱萃水量 `>= 9.5 × 粉量`（對應冰手沖粉水比下限 `1:14.7`）與悶蒸下限 `>= 2.0 × 粉量`，避免萃取不足。
3. **原地數值微調與上下限防呆**：水溫（`80–98°C`）與粉水比（熱手沖 `1:10–1:20`、冰手沖 `1:14.7–1:20`）均支援點擊直接輸入及 `+` / `-` 緊湊步進器（小數比例切換不撐寬格線，並在觸控裝置透過 `::after` 擴展為 `44×44px` 命中區）；研磨參考統一採用純微米粒徑區間（`300-450µm` 至 `950-1150µm`）。
4. **極簡雙速介面與行動端滑出抽屜**：一鍵切換「完整實驗室（Studio）」與「極簡吧檯（Minimalist Barista）」兩種節奏；手機版提供左側滑出式調參抽屜、頂部參數摘要列與左下角浮動「調參」膠囊，並以 `inert` 與焦點回溯確保無障礙操作。
5. **極簡俯視注水導引與流速動力學計時器**：每段注水嚴格區分出水期（Pouring）與沉降滴濾期（Drain Buffer），配備單點水流軌跡俯視導引盤、停壺分隔線、高醒目度建議流速與即時目標水量、下一步注水預告列（切換前 `<= 5s` 琥珀倒數高亮）、SVG 階梯注水曲線與 Zen Barista 全螢幕 `<dialog>` HUD。
6. **SCA 五維感官風味光譜**：根據烘焙度、水溫、粉水比、研磨與攪拌強度即時計算酸質、甜感、醇厚度、餘韻、乾淨度與萃取指數（Extraction Index），保持跨粉量穩定性並提供吧檯過萃／欠萃診斷。
7. **工藝視覺與吧檯小工具**：結合 Living Roast Aura 動態色溫光暈、棉紙纖維底紋、翻頁數字（Odometer）、機械刻度滾輪尺規＋微棘輪音效、按杯數反推換算器（含 `~2.0 × dose` 咖啡粉吸水耗損）、今日靈感盲沖（Mood Brew Matcher）與 Coffee Beans Vault 雙欄烘焙師風味卡牆。

## 三、物理與萃取科學模型

### 3.1 濾杯幾何與特性模型

不同幾何造型的濾杯決定粉床截面深度與排水阻力。切換濾杯時，系統即時重算研磨建議、大粉量調粗門檻、落水秒數與右側濾杯特性介紹：

| 濾杯類別 | 代表器具 | `grindShift` | 排水係數 (`drainScale`) | 粉床指數 (`bedExponent`) | 大粉量調粗門檻 | 感官傾向與主要特性 |
| :--- | :--- | :---: | :---: | :---: | :---: | :--- |
| **錐形 V60** | Hario V60 / Kono / Origami | `0` | `1.00x` | `0.45` | `24g` | 60° 深粉床與肋骨順暢排氣；排水集中、通透感高，呈現明亮果酸與花果層次 |
| **平底蛋糕** | Kalita Wave / B75 / Orea | `0` | `1.08x` | `0.54` | `20g` | 淺寬粉床均勻受水、減少通道效應；流速穩定容錯高，提升焦糖甜感與圓潤度 |
| **梯形扇形** | Melitta / 傳統三孔梯形 | `+1` | `1.16x` | `0.50` | `22g` | 底部小孔形成微浸泡蓄水；自動調粗防過萃，強化濃厚 Body 與焦糖可可餘韻 |
| **浸泡式（搭配浸泡法）** | Switch / 聰明濾杯 | `0` | `1.00x` | `0.45` | `28g` | 閥門控制開關閥浸泡與釋放時間，追求穩定一致性與飽滿甜感 |

#### 8 階純微米粒徑對照（`GRIND_REFERENCE_BANDS`）

為避免單一磨豆機品牌刻度的誤差與介面雜訊，系統全面改以濾網／粒徑微米範圍呈現研磨區間：

| 研磨階級 | 粒徑範圍 | 典型應用情境 |
| :--- | :---: | :--- |
| **極細研磨** | `300-450µm` | 極淺焙高海拔小粉量／高萃取需求 |
| **細研磨** | `450-600µm` | 淺焙錐形濾杯高甜酸表現 |
| **中細偏細** | `550-700µm` | James Hoffmann 旋轉攪拌法等高均勻度配方 |
| **中細研磨** | `600-750µm` | 職人一刀流、中淺焙主流手沖 |
| **中度研磨** | `700-850µm` | 經典三段式、Switch 聰明濾杯浸泡法 |
| **中粗研磨** | `750-920µm` | 中深焙緩衝過萃風險 |
| **偏粗研磨** | `800-1000µm` | 四六法（粕谷哲）基準研磨 |
| **粗研磨** | `950-1150µm` | 松屋流長悶蒸濃縮或大粉量分享壺 |

### 3.3 粉量動態縮放公式（8g–50g）

系統支援 `8g` 至 `50g` 無段與步進調整，依粉床截面積與厚度動態縮放注水速度與滴濾時間：

- `flowScale = (safeDose / 15) ^ 0.35`（`15g` 為 `1.00`，`30g` 為 `1.27`，`12g` 為 `0.92`）
- `bedScale = (safeDose / 15) ^ bedExponent`（依所選濾杯幾何自動帶入 `0.45` / `0.50` / `0.54`）
- `bloomBonus = round((safeDose - 15) * 0.35)`（依粉量增減微調悶蒸排氣時間）

### 3.4 熱手沖 × 冰手沖熱力學模型

切換至「**冰手沖**」模式時，下壺預置純淨冰塊瞬間鎖住高揮發性花果香氣：

1. **水冰重量拆分**：
   - 總目標液重 = `round(粉量 × 粉水比)`
   - 下壺冰塊重 = `round(總液重 × 0.35)`
   - 上壺熱水重 = `總液重 - 冰塊重`（預設占 `65%`）
2. **溶質熱力學補償**：
   - **水溫 `+2°C`**：提高溶質萃取動能（受全局上限 `98°C` 約束）。
   - **研磨調細 1 階**：彌補熱水比例縮減帶來的接觸面積與溶解時間減少。
   - **滴濾修正 `1.15x`**：考量偏細研磨對粉床阻力的影響（松屋法除旁路外維持結構節奏）。
3. **物理下限防呆保護**：
   - **熱水萃出保護**：強制上壺熱水量 `>= round(粉量 × 9.5)`，防止極端比例導致粉床無法充分萃取；冰手沖交互粉水比可調下限為 `1:14.7`（上限 `1:20.0`），確保所有 `8g–50g` 粉量皆可穩定滿足 `35%` 冰塊與 `>= 9.5x` 熱水。
   - **悶蒸保護**：第一段悶蒸水量至少達 `2.0 × 粉量`（例如 `15g` 粉至少 `30g` 悶蒸水）。

### 3.5 水流型態（Flow Profiles）與步驟動力學

系統將每一手沖段落明確分為 **出水注水秒數（Pouring）** 與 **停壺滴漏靜置秒數（Drain Buffer）**，並在自訂步驟支援單段時長 `5–240s`、單段水量 `0–650g` 即時重算：

| 水流型態 | 目標流速 | 安全範圍 | 沉降下限 | 物理作用與用途 |
| :--- | :---: | :---: | :---: | :--- |
| **大水流 (`fast`)** | `4.8 g/s` | `3.5–6.5 g/s` | `6s` | 強攪拌快速拉升水位，適合 4:6 法後段與第一段翻滾粉床 |
| **中大水流 (`medium_fast`)** | `4.0 g/s` | `2.8–5.5 g/s` | `5s` | 適度攪拌且迅速出水，兼顧流速與粉床穩定 |
| **標準水流 (`medium`)** | `3.3 g/s` | `2.2–4.6 g/s` | `4s` | 穩定螺旋繞圈，平衡靜水壓與均勻萃取 |
| **柔和小水流 (`gentle`)** | `2.4 g/s` | `1.5–3.6 g/s` | `3s` | 低擾流柔和滲透，避免細粉過度擾動 |
| **極細點滴 (`drip`)** | `0.7 g/s` | `0.3–1.2 g/s` | `2s` | 松屋流深層無擾悶潤 |
| **旁路直注 (`bypass`)** | `8.0 g/s` | `4.0–12.0 g/s` | `2s` | 不經濾杯直接稀釋調節濃度 |
| **靜置滴漏 (`drain`)** | `0 g/s` | `—` | `—` | 自然落水或加冰急冷攪拌收尾 |

| :--- | :--- | :---: | :--- |
| **四六法（粕谷哲）** | 偏粗研磨（`800-1000µm`） | `1.00x` | 前 `40%` 兩注調整酸甜取向，後 `60%` 三注調節濃度與厚度，每段等水排乾 |

## 四、吧檯體驗與特色模組

- **極簡俯視注水導引盤與下一步提示**：計時運作時，俯視圖以極簡單點游標軌跡區分「繞圈／中心注水」與「停壺分隔線」，同步加大呈現**建議流速（g/s）**與**即時目標水量**，並於底欄提前顯示下一步段名、增量／目標水重與倒數秒數（切換前 `5` 秒自動琥珀高亮）。
- **極簡吧檯 × 完整實驗室雙速切換**：日常專注操作只需切換至極簡吧檯，立即集中顯示核心參數、當前／下一段時間與即時目標；進階調校可切回完整實驗室檢視濾杯橫切面、風味光譜與自訂段落。
- **機械刻度滾輪尺規＋按杯數反推換算器**：拖動 `8g–50g` 粉量尺規提供可靜音的 Web Audio 微棘輪回饋；按杯數反推器（預設 1 至 4 杯／自訂杯量 `80–600ml`）會自動計入咖啡粉吸水耗損（約 `2.0 × 粉量`），直接推算所需咖啡粉克數。
- **今日靈感盲沖（Mood Brew Matcher）**：依照當下想要的香氣、口感與溫度心情，一鍵配對包含手法、烘焙、濾杯與冰熱配置的完整配方。
- **Coffee Beans Vault 咖啡豆專屬評分庫**：採用雙欄烘焙師風味卡牆與風味色票條設計，支援即時搜尋、處理法標籤篩選、排序、多沖煮手法紀錄對照、一鍵套用完整參數（含自訂步驟與冰塊重量）以及 JSON 匯入／匯出備份，所有資料皆儲存於本地 `localStorage`。
- **零原生彈窗交互（Zero Native Popups）**：全站零 `alert()` / `confirm()` / `prompt()`，自訂步驟刪除／重置採就地兩段式防誤觸確認，提醒通知自動掛載於頂層 `<dialog>` 或頁面容器。

## 六、本地開發與快速啟動

專案為**單一靜態檔案零建置（Zero-build）**架構，無需安裝任何前端打包工具即可運行：

### 方式一：Python 內建伺服器（推薦）

```bash
git clone https://github.com/Wu0308/coffee-dial-in.git
cd coffee-dial-in
python -m http.server 3000
```

於瀏覽器開啟：[http://localhost:3000](http://localhost:3000)

### 方式二：Node.js靜態伺服器

```bash
npm start
```

或直接雙擊專案根目錄的 `index.html` 於現代瀏覽器（Chrome / Edge / Safari / Firefox）使用。

## 七、技術規格與版本變更記錄

### 技術規格

- **前端架構**：Vanilla HTML5 + 原生 ES6+（單檔部署於 `index.html`）
- **樣式與字型**：Tailwind CSS Play CDN v3 + Google Fonts（`Plus Jakarta Sans`、`Outfit`、`JetBrains Mono`、`Noto Sans TC`）＋棉紙纖維底紋與暖麻紙色票系統
- **音訊引擎**：Web Audio API（段落提醒雙音和弦、完成和弦與機械尺規微棘輪音效）
- **無障礙與行動適配**：`viewport-fit=cover`、`100dvh`/`92dvh` 動態視口、原生 `<dialog>` 頂層模式、`inert` 抽屜隔離、`44×44px` 觸控擴展熱區、`@media (forced-colors: active)` 支援、全站零 Emoji
- **資料持久化**：瀏覽器本地 `localStorage`（評分庫與 UI 模式偏好）
