## ✨ 核心特色與功能亮點

### 1. 使用者自定義參數與各段注水深度調校
除了系統推薦的標準金杯黃金參數外，BrewCraft 全面支援玩家自定義微調：
- **水溫調校**：支援 `[-]` / `[+]` 增減 1°C 微調，或點擊數值直接輸入指定水溫（80°C ~ 98°C），並附帶「↺ 推薦」一鍵還原。
- **研磨度自選**：內建 7 階精準研磨選單（極細研磨、細研磨、中細偏細、中細研磨、中度研磨、中粗研磨、偏粗研磨、粗研磨），切換沖煮法與烘焙度時自動智慧同步推薦。
- **粉水比微調**：支援 `[-]` / `[+]` 增減 0.5 比例，或點擊直接自訂比率（例：1:15.5），附帶「↺ 推薦」還原。
- **每階段水量與秒數自由編輯**：
  - 點擊「✏️ 自訂各段秒數與水量」即可直接編輯步驟表格。
  - **即時連動計算**：修改任一段注水量，自動累計總水量與反算粉水比；修改注水秒數，自動更新時間區間（Time Range）與預估總沖煮秒數。
  - **自訂注水操作簡記（`note`）**：每一階段皆可自由撰寫個人的注水要領與沖煮心得（例：「中心點極細水流點滴注入，維持粉層濕潤不排乾」），直接留存並呈現在表格、計時指引與評分卡中。
  - **焦點防跳脫體驗**：輸入水量、秒數與簡記時採局部更新，打字順暢不跳游標。
- **一鍵「重新計算」**：任何時候點擊主選單下方的「重新計算」按鈕，系統會將水溫、研磨度、粉水比及所有步驟秒數/水量全數還原為當前手法與風味的黃金推薦標準。

### 2. 萃取科學導向的風味偏好與秒數連動
在左欄「風味偏好」正下方設有**即時萃取原理說明卡片**，依據使用者所選風味偏好即時動態解說，並連動水溫、粉水比與各段落水秒數：
- 🍋 **強調酸質 (Acidity)**：
  - 水溫提高 1°C（如淺中焙 93°C）激發花果揮發酸香氣。
  - **縮短悶蒸至 35 秒**、縮短每段萃取間隔，快速落水避開後段苦澀。
  - 粕谷哲 4:6 法則前段採「前大後小」（24% / 16% 水量），使果酸純淨明亮，總沖煮時間約 2:20。
- 🍯 **突出甜感 (Sweetness)**：
  - 水溫降低 1°C（如淺中焙 91°C）避免高溫燙傷細粉萃出雜苦。
  - 粉水比微幅加寬（1:15.2）；**延長悶蒸至 52 秒**並增加落水間隔，給予焦糖化物質與可溶性糖分充分溶解時間。
  - 粕谷哲 4:6 法則前段採「前小後大」（16% / 24% 水量），極致釋放焦糖甜感，總沖煮時間約 3:00。
- ☕ **追求厚實 (Body)**：
  - 水溫降 2°C、粉水比收窄至 1:14，大幅提高咖啡液 TDS 濃度。
  - 延長浸透接觸時間（+20s），充分浸潤萃取出微乳化咖啡油脂與飽滿醇厚度，總沖煮時間約 3:10。
- ⚖️ **平衡順口 (Balance)**：
  - 92°C 標準水溫、1:15 金杯黃金比例、45 秒標準悶蒸節奏，酸、甜、甘、醇四大維度均衡展現。

### 3. 動態手沖動作引導動畫 (Step Cue Animations)
計時器展開後，介面會根據目前手沖手法與進行中的步驟，播放對應的極簡手沖動態視覺引導：
- 🫧 **溫潤深層悶蒸排氣膨脹（漢堡呼吸動畫）**：所有手沖法悶蒸階段通用，細膩呈現咖啡粉吸水均勻排氣膨脹的咖啡漢堡效果。
- 🌀 **穩定螺旋繞圈注水（擴展同心圓漣漪動畫）**：四六法後段、三段式前段，呈現由內而外的平穩旋轉水流。
- 💧 **垂直中心點滴（垂直水柱漣漪）**：一刀流極細垂直水柱不中斷注水、三段式中心補水。
- 🔄 **旋轉搖晃均勻浸潤（Hoffmann Swirl）**：展示濾杯輕晃旋轉以消除通道效應的動態。
- 🔒 **閥門閉合全浸泡（Switch 聰明濾杯）**：顯示止水閥撥起關閉、熱水全浸泡粉層的動態。
- 🔓 **開閥釋放滴濾（Switch 重力過濾）**：按下開關釋放清澈咖啡液流下的動態。
- ⏳ **自然滴濾收尾（水層緩緩排乾）**：移開濾杯前的平穩滴乾過程。

### 4. 專業級互動式沖煮計時器 (Brewing Timer)
- 🔔 **Web Audio API 柔和合成音效**：
  - 換段前 3 秒輕柔倒數滴答聲（880Hz / 1760Hz）。
  - 換段瞬間和弦合音（523Hz + 659Hz，C5/E5 雙音和弦）。
  - 萃取完成溫暖雙音和聲（523Hz $\rightarrow$ 784Hz，C5 $\rightarrow$ G5）。
- 📊 **注水目標進度條（Progress Bar）**：實時反映當前步驟之秒數進度與水克數目標。
- 🔋 **螢幕防休眠（Screen Wake Lock API）**：沖煮過程中防止手機螢幕自動關閉。
- ⏱️ **真實時間戳校準（VisibilityChange）**：即便切換應用程式或手機分頁休眠，切回時毫秒不差即時校準。
- ☕ **超時滴漏等待模式（Overtime Drip-Through）**：達到預估時間時計時器**不會突然中斷**，而是平滑切換至超時滴漏計時（顯示 `+XX 秒`），讓使用者靜候咖啡滴濾完畢再移開濾杯。

### 5. 咖啡豆評分庫與多手法筆記 (Coffee Beans Vault)
- 🏷️ **建立專屬咖啡豆檔案**：輸入咖啡豆名稱（例：`耶加雪菲 粉紅炸彈`、`哥斯大黎加 蕭邦`）、產區處理法備註。
- 🏆 **單一咖啡豆評分多種手沖法**：同一支豆子可以在庫內評分四六法（4.5 分）、一刀流（4.0 分）等不同手法，直觀比較各手法的風味表現。
- 📝 **完整杯測記錄**：支援 1~5 星評分、6 大風味標籤快速點選（🍋 明亮果酸、🌸 柑橘清香、🍯 焦糖甜感、🌰 堅果可可、☕ 厚實濃郁、🍃 乾淨清爽）及心得備註。
- 📦 **100% 完整保存自訂沖煮步驟**：
  - 保存時自動封裝當時的粉量、水溫、研磨度、粉水比、總水量，以及**各階段注水量、累積水量、注水秒數與自訂操作簡記**。
  - 在歷史評分清單中設有「**📋 沖煮步驟細節（展開詳情 ▾）**」折疊卡片，展開即可完整回顧當時的每一注細節。
- ⚡ **一鍵「套用此參數 ▶」**：點擊歷史評分中的套用按鈕，主畫面立即 100% 還原手法、烘焙度、風味偏好、粉量、自訂水溫、自訂研磨、自訂粉水比與各段秒數/水量/操作簡記！

### 6. 一鍵複製完整配方
點擊右上角「📋 複製配方」，即可將當前配置一鍵格式化複製至剪貼簿，便於分享給好友或記錄在筆記軟體中：
```text
【BrewCraft 手沖咖啡調配指南】
━━━━━━━━━━━━━━━━━━━━━
· 沖煮手法：四六法 (粕谷哲)
· 咖啡烘焙：淺中烘焙
· 咖啡粉量：15g
· 風味取向：突出甜感
─────────────────────
[推薦參數]
· 建議水溫：91°C
· 研磨刻度：偏粗研磨
· 建議粉水比：1:15.2
· 總注水量：228g
· 預估總時間：約 3:04 (共 184 秒)
─────────────────────
[詳細沖煮步驟]
1. 悶蒸: +36g (累計 36g) | 52秒 (0:00 - 0:52) | 由中心向外柔和繞圈，確保浸透並排氣至 0:52
2. 第一段: +55g (累計 91g) | 43秒 (0:52 - 1:35) | 穩定繞圈注水，調節酸甜明亮與焦糖化，落水至 1:35
3. 第二段: +46g (累計 137g) | 33秒 (1:35 - 2:08) | 後60%第一注，維持細水流繞圈，提升萃取乾淨度
4. 第三段: +46g (累計 183g) | 28秒 (2:08 - 2:36) | 提升萃取醇厚度，等水完全落乾再進行下一注
5. 第四段: +45g (累計 228g) | 28秒 (2:36 - 3:04) | 收尾注至目標水量，落乾移開濾杯
━━━━━━━━━━━━━━━━━━━━━
```

## 📖 6 大主流沖煮手法支援

| 沖煮手法 | 創始 / 代表性 | 研磨度推薦 | 萃取核心特性 |
| :--- | :--- | :--- | :--- |
| **四六法 (4:6 Method)** | 粕谷哲 (2016 WBrC 冠軍) | 偏粗研磨 | 前 40% 水量調酸甜（前大後小偏酸、前小後大偏甜），後 60% 調濃度醇厚，每段等水落乾。 |
| **一刀流 (Single Continuous Pour)** | 經典日式極簡流派 | 中細研磨 | 悶蒸後以極細垂直水流連續中心注水不中斷，維持恆定液位，口感極度純淨通透。 |
| **經典三段式 (Classic 3-Stage)** | 傳統精品咖啡金杯標準 | 中度研磨 | 悶蒸、前段繞圈萃取花果香酸甜、後段中心注水補足醇厚度與平衡感。 |
| **James Hoffmann 旋轉法** | James Hoffmann (前世界冠軍) | 中細偏細 | 注入悶蒸水後輕晃濾杯（Swirl）消除通道結塊，後段注水完成後再 Swirl 一次，粉床收杯平整如鏡。 |
| **松屋流 (Matsuya Style)** | 日本松屋咖啡老店 | 粗研磨 | 中心點滴注水、加蓋深悶蒸 3 分鐘釋放極致香氣，僅萃取前段甜感精華，後段移開濾杯以純熱水稀釋 (Bypass)。 |
| **浸泡法 (Switch / 聰明濾杯)** | Hario Switch / Clever Dripper | 中度研磨 | 前段開閥初浸透釋放果酸，後段閉閥全浸泡均勻萃取，按下開關一次過濾釋放，穩定度極高不易失誤。 |

## 📱 PWA 安裝至手機與桌面主畫面

BrewCraft 支援完整 Progressive Web App（PWA）標準，可作為原生應用程式安裝至手機或電腦桌面，享有全螢幕獨立運行體驗：

### 🍎 iOS (iPhone / iPad - Safari)
1. 在 Safari 瀏覽器打開 [線上體驗網址](https://wu0308.github.io/coffee-dial-in/)。
2. 點擊瀏覽器底部的「**分享**」按鈕（帶箭頭的方框圖示）。
3. 往下滑動找到並點擊「**加入主畫面 (Add to Home Screen)**」。
4. 點擊右上角「**新增**」，即可在手機桌面看見專屬高質感咖啡圖示。

### 🤖 Android (Chrome)
1. 在 Chrome 瀏覽器打開 [線上體驗網址](https://wu0308.github.io/coffee-dial-in/)。
2. 點擊右上角選單「**⋮**」。
3. 選擇「**加到主畫面**」或「**安裝應用程式**」。

### 💻 桌面端 (macOS / Windows / Linux - Chrome & Edge)
1. 在網址列右側會出現「**安裝 BrewCraft**」的電腦圖示，點擊即可安裝至桌面應用程式清單。

## 🚀 本地快速啟動指南

BrewCraft 採用純客戶端零依賴設計（Zero Build Step），不需要安裝 Node.js、編譯或建置環境即可直接執行：

### 方式 1：直接開啟
在檔案總管或 Finder 中直接**雙擊 `index.html`**，即可在任何現代瀏覽器（Chrome、Safari、Edge、Firefox）中離線使用。

### 方式 2：使用本地靜態伺服器（推薦）
```bash
# 使用 npm 或 npx 啟動本地輕量伺服器
npx serve .

# 或使用 Python 內建伺服器
python -m http.server 3000
```
瀏覽器訪問 `http://localhost:3000` 即可暢快體驗。

## 🛠️ 技術架構

- **HTML5 & CSS3**：原生語意化標籤，嚴格自適應佈局。
- **Tailwind CSS (CDN)**：現代實用工具優先（Utility-First）樣式庫。
- **純原生 JavaScript (ES6+)**：模組化狀態管理、DOM 操作，無任何重量級外部框架，加載極快。
- **Web Audio API**：純代碼即時合成多段正弦波振盪音效，無需加載音訊檔。
- **Web Storage API (localStorage)**：本地持久化儲存咖啡豆檔案、自訂參數與評分歷史。
- **Screen Wake Lock API**：沖煮期間保持手機螢幕常亮。
- **PWA (Service-Ready & Web Manifest)**：支援離線快取、獨立全螢幕運行模式。
