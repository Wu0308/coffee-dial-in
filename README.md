# ☕ BrewCraft 手沖咖啡參數調配系統

專為手沖咖啡愛好者與精品咖啡玩家設計的極簡純工具型參數計算器。

## 🌟 核心特色

1. **6 大主流沖煮手法**：
   - **四六法 (4:6 Method - 粕谷哲)**：前 40% 水量調酸甜、後 60% 調濃度醇厚，偏粗研磨，每注等水落乾。
   - **一刀流 (Single Continuous Pour)**：細水流連續不中斷，維持水位恆定，口感極度純淨無雜澀。
   - **經典三段式 (Classic 3-Stage)**：前段繞圈萃取果香酸甜，後段中心注水補足醇厚度。
   - **James Hoffmann 旋轉攪拌法**：悶蒸輕晃 (Swirl) 消除通道結塊，粉床收杯平整如鏡。
   - **松屋流 (Matsuya Style)**：中心點滴、加蓋深悶蒸 3 分鐘，萃取前段精華，後段熱水稀釋 (Bypass)。
   - **聰明濾杯 / 浸泡法 (Switch / Clever Immersion)**：全浸泡萃取，開閥釋放，高均勻度不易失敗。

2. **5 段階層烘焙度**：
   - 淺焙 (Light)
   - 中淺焙 (Medium-Light)
   - 中焙 (Medium)
   - 中深焙 (Medium-Dark)
   - 深焙 (Dark)

3. **自由自訂粉量 (8g ~ 50g)**：
   - 附快捷標籤 (12g / 15g / 18g / 20g) 與滑桿微調。

4. **4 大風味偏好導向**：
   - 偏酸 (果酸花香)
   - 偏甜 (焦糖甜感)
   - 偏厚實 (飽滿醇厚度)
   - 平衡 (酸甜苦均衡)

5. **系統即時建議**：
   - 建議水溫 (°C)
   - 研磨刻度（附顆粒對照說明）
   - 粉水比 (1:X)
   - 總注入水量 (g)
   - 詳細分段步驟（步驟名稱、當段水重、累計水重、時間區間、精簡動作要領）

6. **內建互動式沖煮計時器 (Stopwatch)**：
   - 點擊「開始沖煮」伴隨秒數即時高亮當前注水步驟，顯示目標累計水量。
