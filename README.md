## 一、 系統核心特色與設計哲學

BrewCraft 拋棄傳統手沖計時器「固定水量除以秒數」的粗暴簡化，將精品手沖萃取建立在流體力學、熱力學與溶質擴散科學之上：

1. **三維物理自適應引擎**：烘焙度（Light ~ Dark）、粉量（10g ~ 50g）與 6 大經典手法全面動態連動，精確換算粉層厚度阻力、悶蒸排氣時間與水流擴散速度。
2. **濾杯幾何流阻校正**：納入錐形 V60、平底蛋糕與梯形扇形三大幾何結構，即時修正水流阻力與研磨刻度。
3. **急冷冰手沖熱力學補償**：下壺 35% 冰塊 + 上壺 65% 熱水拆分，自動提升水溫與細化研磨，保留高揮發性香氣並防止萃取不足。
4. **注水流速動力學**：每段注水嚴格區分「出水期」與「沉降濾乾期（Drain Buffer）」，動態指示目標流速（g/s）。
5. **SCA 五維感官雷達圖**：基於酸質、甜感、醇厚度、餘韻與乾淨度，即時預測杯測風味走向與吧台萃取診斷。
6. **零原生彈窗內嵌互動**：水溫/粉水比原地微調步進器、自訂步驟雙階段防誤觸確認、原生 Top-Layer Toast 提示，絕不中斷吧台專注。
7. **單一檔案零依賴現代架構**：純原生 ES6+ 與 Tailwind CSS CDN，無任何 npm 打包依賴，內建 Web Audio API 和弦音訊與 LocalStorage 本地評分庫。

## 三、 濾杯幾何與沖煮物理模型

### 3.1 三大濾杯幾何選擇器（Dripper Geometry Selector）

不同幾何造型的濾杯，決定了咖啡粉層的截面厚度、側壁肋骨排氣通暢度與底部排水孔水力阻力。BrewCraft 內建三大物理幾何模型：

| 濾杯幾何 | 代表型號 | 物理特徵與水流行為 | 基準刻度偏移 (`grindShift`) | 建議流速調整 (`flowAdjust`) | 排水阻力係數 (`drainResistance`) |
| :--- | :--- | :--- | :---: | :---: | :---: |
| **錐形濾杯 (Conical)** | Hario V60, Kono, Origami 錐形 | 60° 銳角使粉層中心厚度最深，水流路徑長，垂直排氣順暢。流速最快、酸質與花果香明亮通透。 | `0` (基準) | `0.0 g/s` | `1.0` (通暢) |
| **平底蛋糕濾杯 (Flat Wave)** | Kalita Wave, Origami 平底, April | 平底寬截面使粉層淺而寬，粉床浸泡受水均勻，降低通道效應風險。甜感飽滿、萃取一致性高。 | `+0.5` (偏粗半格) | `-0.15 g/s` | `1.15` (均勻穩定) |
| **梯形扇形濾杯 (Trapezoid)** | Kalita 101/102, Melitta, Clever | 扇形斜坡收窄至底端小孔，底部排水受阻、微浸泡時間長。醇厚度最高、甜感濃郁扎實。 | `+1.0` (偏粗一格) | `-0.30 g/s` | `1.35` (高阻力慢流) |

* **幾何連動機制**：當切換濾杯時，系統自動微調研磨度刻度建議、注水流速上限與各階段沉降濾乾秒數，確保計算出的步驟符合該濾杯的物理特性。

### 3.2 急冷冰手沖模式（Japanese Flash Brew Mode）

急冷冰手沖（Ice Drip / Flash Brew）是利用高溫熱水快速萃出咖啡豆中的芳香精華，滴入下壺預置冰塊中瞬間冰鎮，鎖住極易揮發的花果香氣：

```
             [ 上壺 65% 91°C 熱水快速萃取 ]
                          │
                          ▼
            [ 穿透粉層溶出芳香高溶質濃縮液 ]
                          │
                          ▼
             [ 下壺預置 35% 純淨冰塊 ]
             (瞬間激冷鎖香 · 稀釋至目標金杯濃度)
```

1. **水冰重量拆分**：
   $$\text{總液重} = \text{粉量} \times \text{粉水比}$$
   $$\text{下壺冰塊重} = \text{round}(\text{總液重} \times 0.35)$$
   $$\text{沖煮熱水重} = \text{總液重} - \text{冰塊重}$$
2. **溶質熱力學補償**：
   * **研磨度微調偏細（-0.5 刻度）**：熱水總量縮減為 65%，水粉接觸時間縮短，研磨微細化以增加比表面積，防止萃取不足。
   * **水溫提高（+1°C）**：提升熱水動能，確保中前段高溶質多酚與有機酸能迅速溶出。
3. **悶蒸水量極限安全保護**：
   * 系統確保第一段悶蒸熱水量 $\ge 2.0 \times \text{粉重}$（如 15g 粉至少注入 30g 悶蒸水），上限防護以未扣冰塊前的基準總液重計算，絕不會因扣除冰塊而造成咖啡粉無法充分浸潤排氣。

### 3.3 烘焙度 × 手法 × 粉量三維物理自適應引擎

#### 1. 烘焙度（Roast Level）連續調配
* **淺焙（Light）**：豆體質地堅硬、孔隙緻密，水溶性低。系統配置寬粉水比（1:15.8）、高水溫（93°C）、細研磨，並給予充分悶蒸排氣時間。
* **中焙（Medium）**：焦糖化顛峰，酸甜平衡。系統配置黃金粉水比（1:15.0）、標準水溫（90°C）、中度研磨。
* **深焙（Dark）**：豆體內部深度碳化、油脂浮出，易萃出焦苦。系統配置窄粉水比（1:14.2）、低水溫（87°C）、偏粗研磨，降低過萃苦澀。

#### 2. 粉量動態縮放物理（Dose Scaling）
* 支援 **10g 至 50g** 無段微調。
* 隨著粉量增加，濾杯中粉層厚度呈幾何增加，水流滲透阻力提高。系統引入流速縮放公式：
  $$S = \text{clamp}\left(1.0 + (\text{粉量} - 15) \times 0.02,\; 0.85,\; 1.45\right)$$
* 大粉量時自動擴展各注水段落之出水秒數與沉降滴濾緩衝期，避免水層溢出或流速過高擊穿粉床。

## 四、 注水流速動力學與 SVG 階梯注水曲線

### 4.1 傳統工具的盲點：出水期與滴漏期（Drain Buffer）物理拆分

傳統計算工具將階段水量直接除以階段總秒數，得出如 $1.2\text{ g/s}$ 針狀水柱的荒謬數值。BrewCraft 將每個階段拆分為：

$$\text{階段總時長} = \text{純注水出水秒數 (Pouring)} + \text{水層滲透滴濾秒數 (Drain Buffer)}$$

* **注水出水秒數**：依照該段指定之水流型態目標流速（Target Rate）進行注水。
* **滴濾沉降秒數**：停止注水後，水層在靜水壓與重力作用下穿透粉床、釋放風味並排乾。

---

### 4.2 五大水流型態（Flow Profiles）節奏對照

| 水流型態 | 基準流速 | 安全上限 | 物理機制與攪動強度 (Agitation) | 代表性應用場景 |
| :--- | :---: | :---: | :--- | :--- |
| 🌊 **大水流** | **~4.8 g/s** | 6.5 g/s | 強烈水流動能，創造水層紊流（Turbulence），翻滾粉床並衝散乾粉結塊。 | Hoffmann 第一段、4:6 法後段快速拉升水位 |
| ⚖️ **標準水流** | **~3.2 g/s** | 4.5 g/s | 均勻同心圓螺旋繞圈，維持穩定水層高度與平衡靜水壓。 | 經典三段式注水、4:6 法前段風味調整 |
| 🌿 **柔和小水流** | **~2.8 g/s** | 3.8 g/s | 垂直低落差平穩層流（Laminar Flow），保護粉床天然孔隙結構。 | 一刀流主注水、Hoffmann 第二段溫和補水 |
| 💧 **極細點滴** | **~1.2 g/s** | 2.0 g/s | 極輕傾斜壺嘴，一滴滴均勻點在中心，毛細現象緩慢浸潤排氣。 | 松屋流 30 秒中心點滴深悶蒸 |
| 🫗 **旁路直注 (Bypass)**| **~8.4 g/s** | 12.0 g/s | 移開濾杯直接向分享壺注熱水稀釋，完全不經咖啡粉床。 | 松屋流尾段濃度調節純熱水稀釋 |

### 4.3 SVG 階梯斜率注水曲線與即時 Playhead Tracker

系統以高精度向量 SVG 動態繪製全時程注水座標圖。曲線由**出水爬升斜坡**與**靜置水平走線**交替構成：

```
累積水量 (g)
   ^                     ┌────────── 沖煮完成 (移開濾杯)
   |                  .─'  (水平走線：尾段滴乾 0.0 g/s)
   |               .─'  (陡峭斜坡：大水流注入進行中)
   |            ┌──'  (水平走線：水層沉降靜置)
   |         .─'  (斜坡：標準水流繞圈)
   |      ┌──'  (水平走線：悶蒸充分排氣)
   |   .─'  (斜坡：注水潤濕粉床)
   +──'───────────────────────────────────> 時間軸 (秒)
       ● ─── 發光進度指示球 (Playhead Puck) 即時追蹤
```

* **Playhead Tracker**：計時器運作時，發光指示球即時沿著座標軌道滑動，當前是「正在注水」或「等待滴乾」一目了然。

## 五、 SCA 五維感官風味雷達圖預測引擎

### 5.1 五大感官維度代表意義

```
               酸質 (Acidity)
                   /\
                  /  \
   乾淨度        /    \        甜感
 (Cleanliness) /      \    (Sweetness)
               \      /
                \    /
                 \  /
                  \/
           醇厚度     餘韻
           (Body)  (Aftertaste)
```

1. **酸質 (Acidity)**：明亮活潑之果酸（柑橘酸、蘋果酸）多汁感。
2. **甜感 (Sweetness)**：熟果、蜂蜜與焦糖甜感飽滿度。
3. **醇厚度 (Body)**：舌面重量感、稠度（Mouthfeel）與油脂包覆感。
4. **餘韻 (Aftertaste)**：吞嚥後喉頭留存之生津回甘持久度。
5. **乾淨度 (Cleanliness)**：杯中澄澈透明度，無木質澀感與雜味。

### 5.2 多變數感官綜合演算原理

* **烘焙基盤**：淺焙賦予高酸質與高乾淨度基準；深焙賦予高醇厚度基準。
* **濾杯幾何**：錐形提升酸質與通透度；蛋糕/扇形濾杯強化甜感與 Body。
* **手法特性**：4:6 法前段大水量增強酸質，前小後大增強甜感；一刀流最大化乾淨度；浸泡法極大化醇厚度。
* **研磨阻力**：細研磨增加固形物溶出（提升 Body 與餘韻）；粗研磨保持清亮乾淨。

### 6.1 Zen Barista 沉浸式全螢幕吧台 HUD

專為手沖操作時維持遠距視讀而設計的原生 `<dialog>` 全螢幕專注儀表板：
* **124px 超大字體即時秒數**：搭配 `text-7xl` 累計目標水量，即使站在吧台 1 公尺外手持手沖壺亦能一眼看清。
* **分段注水軌道（Segmented Progress Rail）**：將沖煮全程拆解為獨立注水區塊，即時回饋各區塊進度，完成後點亮翡翠綠。
* **內嵌 Mini SVG 曲線與即時流速儀**：同步顯示建議流速與即時出水/滴漏倒數。
* **64px 巨型底部觸控列**：在行動裝置上固定底部、永不遮擋，支援手套或單指快速操作。

---

### 6.2 零原生彈窗（Zero Native Popups）內嵌互動體系

徹底摒棄瀏覽器原生 `alert()`、`confirm()` 與 `prompt()`，確保操作流暢不被中斷：
1. **水溫與粉水比原地微調步進器（Inline Steppers）**：直接在參數卡內部透過 `+` / `-` 按鈕調整，並提供「重設」按鈕，實時連動雷達圖。
2. **兩段式防誤觸刪除（Two-Step Inline Confirmation）**：自訂步驟刪除、重設自訂參數或重設計時器時，按鈕原地變換為橙紅色的「確認刪除？」狀態，若 3 秒內未點擊則自動安全復原。
3. **頂層原生 Toast 提示系統（Dialog Top-Layer Toast）**：掛載於最頂層，即使在全螢幕 Zen HUD 模式下亦不會被 backdrop 遮蔽。

---

### 6.3 自訂步驟動態增刪段落與即時流力重算

* **動態增減步驟**：在「自訂步驟」模式下，可自由點擊「+ 新增步驟」擴充注水階段，或刪除冗餘段落。
* **水流型態即時切換**：每段步驟均可獨立選擇大水流、標準水流、柔和小水流、極細點滴或旁路直注，水力學引擎立即重新計算出水秒數與沉降秒數。
* **即時粉水比動態校驗**：手動微調各段水量時，累計水量、粉水比與警示動態局部更新，維持輸入焦點不跳脫。

---

### 6.4 Coffee Beans Vault 咖啡豆專屬評分庫

* **參數完整封裝**：儲存時完整封裝豆名、烘焙度、產區、處理法、沖煮模式（熱/冰）、濾杯幾何、粉量、水溫、研磨度、粉水比與所有自訂注水段落。
* **一鍵套用復刻**：在清單中點擊「套用此參數」，主介面 100% 復原該次沖煮的所有物理細節。
* **JSON 匯入 / 匯出備份**：支援將整個評分庫匯出為標準 JSON 檔案，或自其他裝置匯入。
* **本地 LocalStorage 持久化**：資料完全保存在使用者瀏覽器端，保護個人隱私。

---

### 6.5 精品儀表 UI 質感、分艙托盤與階梯注水膠囊

* **陶瓷／手抄紙立體光影**：全卡片採用雙層內外微陰影（`inset 0 1px 0 rgba(255,255,255,0.9)` + 外層立體投影），層次精緻柔和。
* **三大功能分艙托盤（Trays A, B, C）**：
  * **分艙 A（幾何與溫層）**：`01` 沖煮模式、`02` 濾杯幾何
  * **分艙 B（咖啡豆核心規格）**：`03` 烘焙度、`04` 咖啡粉量（附自訂手抄滑桿）
  * **分艙 C（風味與進階調校）**：`05` 風味偏好、風味萃取導引提示
* **Split Water Pill 階梯注水膠囊**：詳細步驟卡片內嵌本段注入量（`+45g`）、累計目標量（`累計 146g / 65%`）與底部微進度條。
* **行動端置頂毛玻璃浮動計時列**：手機版下滑瀏覽時，計時器控制列平滑置頂浮動（`sticky top-2 z-30`），操作不迷航。

## 七、 6 大經典手沖手法科學配置模型

| 沖煮手法 | 推薦濾杯 | 研磨度建議 | 水溫配置 | 粉水比 | 萃取核心邏輯 | 適用豆種與風味呈現 |
| :--- | :--- | :--- | :---: | :---: | :--- | :--- |
| **粕谷哲 4:6 法** | 錐形 / 蛋糕 | 偏粗研磨 | 92°C | 1:15.0 | 前 40% 水量（2 注）決定酸甜平衡；後 60% 水量（3 注大水流）拉升濃度與厚度。每段等水排乾。 | 淺焙至中深焙皆宜，層次明晰，酸甜多汁，容錯率極高。 |
| **經典三段式** | 錐形 / 扇形 | 中細研磨 | 90°C | 1:15.0 | 悶蒸 40s 後分兩段注水（第 1 段中水流繞圈 $55\%$，第 2 段細水流補水 $45\%$）。 | 適合所有日常精品豆，風味均衡對稱，花果酸甜與 Body 俱佳。 |
| **James Hoffmann V60** | 錐形 V60 | 中細偏細 | 94°C | 1:16.7 | 悶蒸水為粉量 3 倍並 Swirl 消除結塊；第 1 段大水流注入至 60% 總量；第 2 段溫和細流補滿並再次微晃。 | 適合優質淺焙產區豆，極高的均勻萃取率，香氣奔放。 |
| **職人一刀流** | 錐形 V60 | 中細研磨 | 91°C | 1:14.7 | 溫和悶蒸 35s 後，維持超細垂直層流由內向外緩慢繞圈，長達 65 秒不間斷注滿。 | 適合花果香突出的耶加雪菲或藝妓，極致純淨，無雜澀感。 |
| **松屋法 (Matsuya)** | 錐形 / 扇形 | 粗研磨 | 88°C | 1:14.3 | 中心點滴潤濕後加蓋深層悶蒸 3 分鐘；中心大水流萃取至 55% 水量後立即移杯，加熱水 Bypass 稀釋。 | 適合中深焙曼特寧或肯亞，醇厚濃縮但完全無焦苦尾韻。 |
| **Switch 聰明濾杯** | 浸泡專用濾杯 | 中度研磨 | 93°C | 1:15.0 | 前 35s 開閥初浸潤排氣滴出明亮果酸；隨後閉閥注入剩餘 60% 水量全浸泡 85s；按下開關一次過濾釋放。 | 適合追求厚實甜感與操作一致性的玩家，失敗率近乎為零。 |

## 九、 本地開發與快速啟動指南

BrewCraft 採用**零建置（Zero-build）**純前端現代工藝，無需安裝 Node.js、npm 或任何打包編譯工具，單一靜態檔案即可立即運作。

### 方式一：Python 內建伺服器（推薦）
```bash
git clone https://github.com/wu0308/coffee-dial-in.git
cd coffee-dial-in
python -m http.server 3000
```
開啟瀏覽器訪問：`http://localhost:3000`

### 方式二：Node.js http-server
```bash
npx http-server -p 3000
```

### 方式三：直接開啟
雙擊專案目錄下的 `index.html`，即可直接在任何現代瀏覽器（Chrome, Edge, Safari, Firefox）中流暢運行。
